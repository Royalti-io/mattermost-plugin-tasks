# Security

Please do not open a public issue for a vulnerability. Report it privately through
GitHub's "Report a vulnerability" (Security tab) on this repository, with steps to
reproduce and the plugin and Mattermost versions.

Things worth reporting: a way to read or change a task without access to its channel,
a way to forge or replay a webhook signature, or anything that lets a non-admin run
the admin endpoint.

You can expect an acknowledgement within a few working days. Supported versions: the
latest release.
